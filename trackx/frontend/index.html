About

Advanced Operating Systems mini project

All scheduling math runs in C (backend/algorithms.c). The Python server loads it as a shared library, or the browser loads the optional WebAssembly build. This page only displays what the C engine returns.

Conventions. SCAN and C-SCAN travel to the disk edge. LOOK and C-LOOK stop at the last request. Return jumps in C-SCAN and C-LOOK count toward total movement. Duplicate requests are kept and cost zero.

Algorithms. FCFS serves requests in arrival order. SSTF picks the nearest request. SCAN sweeps like an elevator. C-SCAN sweeps one way and jumps back. LOOK and C-LOOK are the same without going to the edge.
